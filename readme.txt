Build and manage product launch decks in WordPress.

== Description ==

LaunchDek is a WordPress plugin scaffold for building and managing product launch decks.

= Features =

* Modular class-based architecture
* Admin dashboard and settings pages
* Settings API integration with sanitized options
* Activation redirect and uninstall cleanup
* Translation-ready with a dedicated text domain

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **LaunchDek** in the admin sidebar to get started.

== Frequently Asked Questions ==

= What does this plugin do? =

This is the initial scaffold for LaunchDek. Extend it with deck management, templates, and frontend rendering as needed.
